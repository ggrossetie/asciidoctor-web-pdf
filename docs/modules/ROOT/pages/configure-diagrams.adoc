= Diagrams

You can use the https://github.com/asciidoctor/asciidoctor-kroki[Asciidoctor Kroki extension] to render diagrams in your PDF.
In this example, we create a file named `piracy.adoc` with the following content:

.piracy.adoc
[source]
----
= Piracy

Piracy is an act of robbery or criminal violence by ship upon another ship,
typically with the goal of stealing rum and other valuable items or properties.

Here's what a pirate looks like!

[nomnoml]
....
[Pirate|eyeCount: Int|raid();pillage()|
  [beard]--[parrot]
  [beard]-:>[foul mouth]
]

[<abstract>Marauder]<:--[Pirate]
[Pirate]- 0..7[mischief]
[jollyness]->[Pirate]
[jollyness]->[rum]
[jollyness]->[singing]
[Pirate]-> *[rum|tastiness: Int|swig()]
[Pirate]->[singing]
[singing]<->[rum]
....
----

https://kroki.io/[Kroki] supports more than a dozen diagram libraries.
In the above example, we are using the https://github.com/skanaar/nomnoml[nomnoml] UML diagram library.

[NOTE]
====
You will need to install `asciidoctor-kroki` using `npm i asciidoctor-kroki`.
====

You can use the following command to generate a PDF:

[source,sh]
----
asciidoctor-web-pdf --require asciidoctor-kroki piracy.adoc
----

Here's the result: https://github.com/ggrossetie/asciidoctor-web-pdf/blob/main/examples/document/piracy.pdf[piracy.pdf]
